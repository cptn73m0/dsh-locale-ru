# Changelog

## 0.2.0 — 2026-11-06

DeepSeek Harness 0.2.2 добавил официальную локализацию, включая русский язык,
поэтому пакет больше не нужен и в 0.2.2+ не загружается: язык `ru` и словари
для всех разделов уже зарегистрированы официально, а старая версия пакета
падает при загрузке (`dsh-locale-ru: failed`).

- Установщик языкового пакета больше не собирается. Вместо него релиз содержит
  `dsh-locale-ru-cleanup-0.2.0.exe` — одноразовое средство удаления пакета 0.1.x.
- Средство очистки запускает старый деинсталлятор (если пакет ставился через `.exe`),
  чистит зависимость и запись загрузчика в профиле `desktop`, удаляет каталог
  `~/.dsh/locale-packs/ru` и запись из «Приложений и возможностях».
- README и release notes объясняют, как включить встроенный русский язык.
- Релиз v0.1.2 и более ранние остаются доступны для DSH ≤ 0.2.1.

## 0.1.2 — 2026-10-25

Перевод обновлён для DeepSeek Harness 0.2.1-rc.3.

- Добавлены переводы новых меню «Ещё» (More): кнопки в левой боковой панели, в заголовке представлений сеанса и на панели «Начало» справа.
- Переведены два пункта меню: «Другие плагины» и «Создать свой плагин», а также черновики запросов для режима создания плагина.
- 2910 строк в 64 пространствах имён клиентских плагинов.

## 0.1.1 — 2026-10-19

- Установщик явно передаёт путь профиля, не полагаясь на переменные окружения.
- Проверены установка и удаление `.exe` в изолированном профиле.

## 0.1.0 — 2026-10-19

Первый выпуск.

- Русский язык (`ru`) зарегистрирован как языковой пакет DSH.
- 2901 строка в 63 пространствах имён клиентских плагинов.
- Установщик `.exe` (Inno Setup) и архив ручной установки.
- Автоматическая сборка и публикация релиза в GitHub Actions.
